# 执魔 · 浏览器单机 RPG

> **v1.7.1** · 零构建 · 完全数据驱动 · 原生 HTML/CSS/JS + ES Modules

🕹️ **在线试玩**：<https://seekersung.github.io/the-demon-s-grip/>　·　📦 **GitHub**：<https://github.com/SEEKERSUNG/the-demon-s-grip>

魔幻传奇题材的浏览器单机游戏。你从异世穿越而来，在东海渔村生活多年，直到魔潮一夜踏碎故乡——从此踏上讨伐魔王、成为新魔王、再以百万魔军调停三族战争的三章旅程。

所有道具、NPC、任务、地图、章节**都是数据条目**，可无限扩展，核心引擎零硬编码。

## 特性

- **节点式探索地图**：区域 → 地点 → 交互节点（战斗/宝箱/NPC/事件），纯数据驱动
- **回合制战斗**：攻击/技能/道具/防御/逃跑，技能表驱动，掉落与经验升级
- **自动战斗**：战斗指令栏一键「🪄 自动战斗」——默认使用背包内全部恢复道具，自动决策嗑药/治疗技能/攻击技能/普攻，胜利自动续下一场，血量危险且无恢复手段自动停止，也可随时手动停止
- **任务系统**：多阶段主线 + 支线，talk/kill/explore/collect 四类目标，链式解锁 + 前置门禁；任务日志带 📍 目标导航路径与「🧭 快速前往」一键直达目标地点
- **对话树**：分支选择、条件分支、领任务/交任务/开商店/恢复
- **章节引擎**：主线 endQuest 完成 → 自动章节过渡 + 过场演出
- **商店交易**：物品仅在商店出售；可装备物品卡片直接显示属性加成（无需进装备栏对比）；商店买/卖、旅店恢复
- **快捷导航**：底部固定栏（🎒背包·📋任务·🧙状态），探索中一键直达，返回直接回到游戏画面（无需经过菜单中转）
- **物品百科**：菜单内全量道具图鉴——稀有度/属性/等级需求/持有数量，**获取途径由内容数据自动汇总**（商店/掉落/宝箱/事件/任务奖励/开局携带），新增内容零配置自动纳入
- **存档**：localStorage 4 槽位 + 独立自动存档位（不覆盖手动存档），SCHEMA_VERSION 版本化迁移；**存档导出/导入**（JSON 文件备份/迁移）；每 60 秒 + 章节里程碑自动保存
- **可复现**：seeded RNG + 无 DOM 回放，四套 Node 验证脚本

## 快速开始

```bash
cd game
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> 零构建，无任何依赖。也可直接双击 `index.html`，但个别浏览器对 `file://` 下的 ES Module 有限制，推荐用静态服务器。

## 开局指南

新档自带**生锈短剑（已装备）**与**5 草药 + 3 药水**。

1. 与**村长福伯**对话接主线「渔村之殇」
2. 到**铁匠阿伟（商店）**买铁剑（70 金，开局 80 金够用）
3. **旅店老板娘（旅店）**可完全恢复体力
4. 再去**染血滩涂**清史莱姆，稳扎稳打升到 2 级
5. 2 级后进**海蚀洞穴**，逐步推进主线

打不过就退守史莱姆刷经验、去商店补给；多余物品可在商店出售换金币。

## 系统一览

- **探索**：进入地点 → 生成节点 → 点击分发（战斗/宝箱/NPC/事件/离开）
- **战斗**：按速度决定先手，玩家先手/后手两条流程；敌我共用技能表与伤害公式
- **任务**：事件驱动目标进度，counts 按「阶段:目标」隔离；对话接取/交还
- **剧情门禁**：统一走 `state.flags`（`FLAG_*`），引擎不硬编码剧情
- **章节**：数据条目，`endQuest` 完成自动 `finishChapter`

## 目录结构

```
index.html               入口（挂载 #app + toast 层）
css/                     base（主题/基础）/ screen（屏幕）/ combat（战斗）
js/
  core/                  引擎：state/save/rng/observer/events/validate/game/version
  systems/               游戏系统：combat/quests/dialogue/explore/shop/equipment/…
  content/               ★ 全部游戏内容（数据），改这里即可扩展
  ui/                    界面：main（启动/路由）/ screens（屏幕）/ combatScreen
scripts/                 check / playthrough / uiSmoke / balance 四套验证
doc/                     技术文档（架构 / 数据Schema / 系统 / 扩展 / 测试）
```

## 更新日志

### v1.7.1 — 任务快速前往

**新功能：任务快速前往**

### v1.7.0 — 自动战斗

**新功能：自动战斗**
- 战斗屏指令栏新增第 4 位「🪄 自动战斗」（攻击/技能/道具旁），点击即开始接管当前战斗——不设独立设置屏
- **恢复道具白名单**：默认自动使用背包内全部恢复类道具（首次开始时物化为白名单），白名单外的道具绝不自动消耗
- **自动决策**（`js/systems/autoBattle.js` 纯逻辑，node 可测）：血量 ≤ 撤退线 → 先嗑药 → 治疗技能 → 无恢复手段则逃跑退出；血量 ≤ 回血线 → 治疗技能（省药）→ 嗑药；其余 → 最强可用技能 → MP 不足先补魔力药 → 普攻；攻击目标固定为血量最低的存活敌人（快速减员）
- **默认阈值**：回血线 50%、撤退线 25%（`uiState.auto` 初值）
- **胜利自动续场**：结算后检查状态自动开下一场；血量危险且无恢复手段、章节过场、地点无敌人时自动停止并提示原因
- **随时手动接管**：自动战斗面板「⏹ 停止自动战斗」转手动操作，「💨 立即撤退」停止并逃跑；读档/新游戏/回标题自动复位
- 战斗屏自动战斗面板实时显示「下一动」预判、当前场次与血量阈值

**体验优化：任务地图路径**
- 任务日志每个目标下方显示「📍 世界地图 → 区域 → 地点」导航路径（talk → NPC 所在地、kill → 含该敌人的全部地点、explore → 地点本身），BOSS 与任务位置一目了然
- 目标地点被锁定时附带 🔒 原因（如「需要等级 Lv.14」）；collect 目标显示物品百科「获取途径」；待交还任务显示回找委托人的路径
- 纯内容反查零硬编码（`quests.objectiveNav` / `questTurnInNav`），新增任务/地点/怪物自动纳入

### v1.6.0 — 物品百科 + 引擎优化

**新功能：物品百科**

## 数据引用约定

- 每条记录 `id` 唯一（英文大写蛇形），显示用中文 `name`/`desc`
- 外键一律存 id 字符串（`drops.item`、`objectives.target`、`npcs.dialogue`…）
- 任务目标类型：`talk`(NPC) / `kill`(敌人) / `explore`(地点) / `collect`(道具)
- 剧情门禁统一走 `state.flags`（`FLAG_*`）
